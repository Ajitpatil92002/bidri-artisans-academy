# bidriart.com

An ecommerce store for Bidri art, with stories about the craft and its artisans.

Built with Next.js, TypeScript and Tailwind CSS. Payments run through Razorpay.

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
