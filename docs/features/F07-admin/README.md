# F07 — Admin panel

**Status:** Done
**Milestone:** M5
**Design:** Ours, in the landing page style (D-014)

## Scope
- Dashboard: recent orders, sales total, low stock
- Products with image upload, stock and draft/active status
- Categories, artisans and journal posts
- Orders: change status, add tracking, record refunds, see the timeline
- Customers list, contact messages, newsletter list
- Settings: shipping fee and free-shipping threshold

## Acceptance criteria
- [x] Only `admin` users can reach any admin page or action
- [x] A product can be created, photographed and published with no code
- [x] Marking an order shipped with tracking emails the customer
- [x] Products that appear on past orders can be archived, not deleted
